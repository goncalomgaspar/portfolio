## 🚀 Academic Projects

### 📌 Final Project – Smart Objects Addressing  
**Degree:** Bachelor’s in Computer Science – Polytechnic Institute of Leiria (2025)  
- **Description:** Developed a web application integrated with IoT concepts for addressing smart objects using georeferencing and digital identification. The platform allowed the creation, management, and location of physical objects (mobile or static) through unique, user-friendly Smart Addresses integrated with an interactive map.  
- **Technologies:** Node.js, Express.js, Vue.js, PostgreSQL, REST APIs, Google Maps API  
- **Supervisors:** Prof. Nuno Alexandre Ribeiro da Costa & Prof. António Manuel de Jesus Pereira

### 📌 DAE – Enterprise Applications Development
**Project:** Smart Packaging Monitoring Platform  
- **Role:** Backend  
- **Description:** Enterprise application to monitor sensor-equipped packaging, integrating with logistics and order management systems.  
- **Details:**  
  - **Backend:** Built with Jakarta EE and PostgreSQL, exposing REST services for integration with logistics, operational management, and customer support systems.  
  - **Features:** Monitoring of shipments, association of sensors, and alerts for critical events (e.g., impact detection, temperature variation).  
  - **Highlights:** Modular enterprise architecture (MVC, ORM, concurrency), focusing on scalability and integration with external systems.  

👉 [View Repository](https://github.com/JorgeSilvaESTG/ProjetoDAE)

### 📌 DAD – Distributed Applications Development
**Project:** Memory Game Platform  
- **Role:** Backend & Frontend  
- **Description:** Development of a web-based SPA (Vue.js) memory game platform with single-player and multiplayer modes, a virtual credit system, game history, and statistics.  
- **Details:**  
  - **Frontend:** SPA in Vue.js with user authentication, multiplayer interface, and statistics dashboards.  
  - **Backend:** REST API + WebSocket server with relational database.  
  - **Highlights:** Implemented personal and global leaderboards, virtual credit system integrated with an external payment service, and an administration module.  

👉 [View Repository](https://github.com/goncalomgaspar/dad2024-25)

### 📌 IS – Systems Integration
**Project:** SOMIOD – Service Oriented Middleware for Interoperability and Open Data  
- **Role:** Backend & Frontend  
- **Description:** Development of a service-oriented middleware for IoT interoperability, supporting applications, containers, records, and notifications.  
- **Details:**  
  - **Backend:** RESTful API for CRUD operations on resources (applications, containers, records, notifications), with support for HTTP and MQTT notifications.  
  - **Frontend:** Test applications to validate middleware operations, including use cases like a smart lightbulb controlled through a mobile app.  
  - **Highlights:** Promoted interoperability and open data, adopting Web standards for consistent access and manipulation of resources.  

👉 [View Repository](https://github.com/goncalomgaspar/ProjSomiodISSolution)
